# Campus Clubs

A small Next.js + TypeScript app. Open the exam brief and complete the five tasks.

```
npm install
npm run dev      # http://localhost:3000
npx tsc --noEmit # type check
npm run build    # must finish with no errors
```

Task 5 needs a new file: `app/clubs/[id]/page.tsx` (the card links already point to it).
